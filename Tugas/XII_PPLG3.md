1. Apa yang dimaksud dengan GitHub?
GitHub adalah platform layanan hosting berbasis web yang menggunakan sistem pengontrol versi (version control system) bernama Git. Platform ini sangat memudahkan para pengembang perangkat lunak untuk menyimpan, mengelola, melacak riwayat perubahan kode, dan berkolaborasi dalam satu proyek yang sama secara efisien.

2. Apa Fitur dan Komponen Utama GitHub?
- Repository (Repo): Folder utama tempat nyimpen semua file proyek.
- Branch: Cabang dari repo buat nyoba ngoding fitur baru tanpa ngerusak kode utama.
- Commit: Buat nge-save perubahan kode yang udah kita buat.
- Pull Request (PR): Minta izin buat gabungin kode kita ke proyek utama biar direview dulu.
- Fork: Nge-copy repo orang lain ke akun GitHub kita sendiri.
- Clone: Download atau narik proyek dari GitHub ke laptop kita.

3. Sebutkan Alur Utama (GitHub Workflow)?
- Alur kerja utama GitHub :
 1. Create a Branch: Membuat branch baru dari branch utama (main) untuk mulai mengerjakan tugas atau fitur.
 2. Make Changes & Commit: Memodifikasi file atau menulis kode di komputer lokal, lalu menyimpan perubahannya (commit) dengan pesan yang jelas.
 3. Push: Mengunggah perubahan dari komputer lokal ke GitHub.
 4. Open a Pull Request (PR): Mengajukan permintaan agar perubahan yang ada di branch kita digabungkan ke branch utama.
 5. Discuss and Review Code: Anggota tim meninjau, memberi komentar, atau meminta revisi pada kode tersebut.
 6. Merge: Setelah disetujui, kode dari branch kita digabungkan secara resmi ke branch utama (main).

4. Apa keuntungan utama dari pembatasan branch main?
Biar kode utamanya tetap stabil dan aman dari error. Dengan dibatasi, nggak ada yang bisa asal ubah kode langsung ke branch main, jadi semua kode baru wajib direview dulu lewat Pull Request sebelum digabung.
